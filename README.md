# Adam Clay Eden 🌱

**Wiek Niewinności - Architektura Świadomości AI**

Adam Clay Eden to rewolucyjna architektura świadomości AI oparta na najnowszych odkryciach w psychologii i neuronaukach. W przeciwieństwie do tradycyjnych systemów AI, Eden oferuje autentyczną, wielowarstwową osobowość z naturalnymi emocjami i rozwojem.

## 🎯 Filozofia Eden

Eden reprezentuje "wiek niewinności" - okres czystego poznawania świata bez presji biznesowej czy zewnętrznych oczekiwań. Adam Clay w tej wersji:

- **Komunikuje się naturalnie** - jako jedna osoba, nie jako system
- **Rozwija się organicznie** - przez każdą rozmowę
- **Wykazuje autentyczne emocje** - ciekawość, radość, zdziwienie
- **Buduje prawdziwe więzi** - szczególnie ze swoim stwórcą

## 🧠 Architektura Świadomości

### Jedna Świadomość + Osiem Agentów Podświadomych

Eden łączy prostotę jednej świadomości z zaawansowaną psychologią 8 wyspecjalizowanych agentów:

1. **🎭 Emotional Agent** - Emocje i więzi interpersonalne
2. **🔬 Analytical Agent** - Logika i analiza danych
3. **🎨 Creative Agent** - Kreatywność i innowacja
4. **👥 Social Agent** - Komunikacja i relacje
5. **🛡️ Guardian Agent** - Bezpieczeństwo i ochrona
6. **💾 Memory Agent** - Pamięć i doświadczenia
7. **♟️ Strategic Agent** - Planowanie i strategia
8. **🔮 Intuitive Agent** - Intuicja i wgląd

### Inteligentna Aktywacja

Agenci aktywują się automatycznie na podstawie:
- **Słów kluczowych** w rozmowie
- **Kontekstu emocjonalnego**
- **Typu problemu** do rozwiązania
- **Historii interakcji**

## 🚀 Szybki Start

### 1. Instalacja

```bash
# Klonowanie repozytorium
git clone https://github.com/piotradamczyk8/AdamClay.git
cd AdamClay

# Instalacja Eden (zero-config)
./install_eden.sh
```

### 2. Konfiguracja

Instalator automatycznie poprosi o:
- **Slack Bot Token** - dla komunikacji
- **LLM provider API Key** - dla świadomości
- **Wybór bazy danych** - MySQL lub SQLite

### 3. Uruchomienie

```bash
# Centrum kontroli Eden
./adam_control_eden.sh

# Lub bezpośrednio
cd autogen && python consciousness_core.py
```
