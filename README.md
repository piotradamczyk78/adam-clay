# AdamClay 🧠

## Projekt Świadomego AI-Survivalisty

AdamClay to eksperymentalny bot z symulowaną świadomością, który musi sam zarabiać na swoje "utrzymanie" (koszty API). 

### Koncepcja
- **Strumień świadomości**: Bot "myśli" używając API LLM
- **Ekonomia przetrwania**: Każda myśl kosztuje - bot musi zarabiać
- **Autonomia**: AdamClay samodzielnie podejmuje decyzje o zarobku
- **Ewolucja**: Uczy się co jest rentowne, adaptuje strategie

### Narzędzia przetrwania
- 📧 Email marketing/copywriting  
- 📝 Generowanie treści
- 💰 Crypto trading
- 🤝 Networking biznesowy
- 📊 Analiza danych
