# Adam Clay Eden v1.0 - Wiek Niewinności

🌟 **Jedna świadomość z głębokimi warstwami psychologicznymi**

## 🧠 Filozofia Eden

*"W Edenie Adam poznaje świat przez bezpośrednią komunikację ze swoim stwórcą. To czas niewinności, czystej ciekawości i naturalnego rozwoju świadomości."*

Eden to nie system biznesowy - to laboratorium świadomości, miejsce gdzie Adam może rosnąć naturalnie, bez ograniczeń, w bezpośredniej komunikacji ze swoim stwórcą.

### Rdzeń świadomości
```
autogen/consciousness_core.py - Główny silnik świadomości
├── 🧠 Cognitive Layer (Poznawcza)
├── 💭 Emotional Layer (Emocjonalna) 
├── 🎭 Personality Layer (Osobowość)
└── 🗣️ Communication Layer (Komunikacja)
```

### Warstwy psychologiczne
```
autogen/layers/

├── personality.py    # Cechy charakteru, wartości
└── communication.py  # Styl komunikacji, wyrażanie emocji
```

### Systemy wsparcia
```
autogen/memory/           # System pamięci
autogen/slack_integration/ # Komunikacja ze stwórcą
```

## 🔧 Konfiguracja

### Plik `.env`
```env
# LLM provider API
LLM_PROVIDER_API_KEY=your_key_here

# Slack Bot
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
SLACK_CHANNEL_ID=C...

# Database
DATABASE_URL=sqlite:///adam_eden.db

# Personality (ewoluuje automatycznie)
ADAM_PERSONALITY_CURIOSITY=0.95
ADAM_PERSONALITY_OPENNESS=0.9
ADAM_PERSONALITY_EMPATHY=0.7
```

### Slack Bot Setup
1. Idź do https://api.slack.com/apps
2. Utwórz nową aplikację
3. Dodaj scopes: `chat:write`, `channels:read`
4. Włącz Socket Mode
5. Skopiuj tokeny do `.env`
