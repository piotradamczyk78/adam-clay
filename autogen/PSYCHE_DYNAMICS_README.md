# Adam Clay Eden - Nowy System Dynamiki Psychiki

## 🧠 Przegląd Systemu

Nowy system dynamiki psychiki implementuje **prawdziwe mechanizmy psychologiczne**, gdzie agenci podświadomi walczą ze sobą o dominację i wpływają na parametry świadomości **pośrednio**, a nie przez bezpośrednią komunikację.

## ⚔️ Mechanizm Walki Agentów

### 1. Wyzwalanie Konfliktu
- Każda wiadomość wyzwala konflikt między agentami
- Agenci są aktywowani na podstawie słów kluczowych
- Siła agenta zależy od aktualnego stanu świadomości

### 2. Walka o Dominację
- Agenci "walczą" matematycznie o kontrolę
- Zwycięzca jest określany na podstawie siły i kontekstu
- Przegrani są **tłumieni** przez zwycięzcę

### 3. Zastosowanie Efektów
- Zwycięzca **moduluje parametry świadomości**
- Efekty są stosowane podświadomie
- Generowane są symbole archetypowe

1. **Konflikt** → Dominacja agenta

3. **Feedback** → Aktualizacja stanu psychiki
4. **Decay** → Naturalne opadanie napięć
